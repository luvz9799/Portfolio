Sarola Field Database

A field-survey app for a new colony launch. The team records villages, local leaders, shops and fairs around Sarola. Instead of typing forms, a field person speaks a Hindi voice note after each meeting, and AI turns it into ready-to-save database entries.

const chunks = splitPcm(await toPcm16k(blob));
let text = '';
for (let i = 0; i < chunks.length; i++) {
  step(`Listening… ${i + 1}/${chunks.length}`);
  const req = { audio: b64(wav(chunks[i])), session, index: i };
  // retry once, so one bad chunk can't drop the whole note
  const r = await api('transcribe', req)
    .catch(() => api('transcribe', req));
  text += (r.text || '') + ' ';
}
await runExtract(text.trim());   // → LLM → entries
index.htmlHindi-aware fuzzy matching
// fold spelling variants: aa→a, ee/y→i, oo→u, w→v
const fold = s => norm(s)
  .replace(/aa/g, 'a').replace(/ee|iy|y/g, 'i')
  .replace(/oo|ou/g, 'u').replace(/w/g, 'v')
  .replace(/(.)\1+/g, '$1');

function findByName(list, name, fuzzy) {
  const k = fold(name);
  let c = list.filter(r => fold(r.Name) === k);
  if (!c.length && fuzzy && k.length >= 5)
    c = list.filter(r => lev(fold(r.Name), k) <= 1);
  return c[0] || null;
}

How I build

Secrets stay out of code

API keys live in GitHub Secrets and Apps Script PropertiesService, never in the repo.

Public endpoints are authenticated

The notify API verifies a Firebase ID token before it does anything.

Built for real limits

Pushes go out in batches of 500 (the FCM limit) and AI audits are capped per run to stay inside quotas.

Structured AI output

Gemini returns a fixed JSON schema, so results go straight into a spreadsheet.

Safe concurrent writes

LockService stops two users from overwriting each other's rows.

Runs on free tiers

GitHub Actions, Vercel, Firebase and Apps Script: no servers to rent or patch.
